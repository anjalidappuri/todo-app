\# To-Do App



A simple To-Do application for creating and managing daily tasks.



\## Features



\* Add new tasks

\* View all tasks

\* Update tasks

\* Delete tasks

\* Mark tasks as completed

\* Simple and easy-to-use application



\## Technologies Used



\* Node.js

\* Express.js

\* MongoDB

\* JavaScript

\## Installation



Clone the repository:



```bash

git clone https://github.com/anjalidappuri/todo-app.git

```



Go to the project folder:



```bash

cd todo-app

```



Install the required dependencies:



```bash

npm install

```



\## Running the Application



Start the backend:



```bash

npm run dev

```



The backend will run on:



```text

http://localhost:5000

```



\## Usage



1\. Open the application.

2\. Add a new task.

3\. View your tasks.

4\. Mark tasks as completed when finished.

5\. Update or delete tasks when required.
